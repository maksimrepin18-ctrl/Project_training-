# Project_training-
Практика в обучении. Тренировочные датафреймы сгенирированные при промощи ИИ.

Файл Trening_full - это полный цикл очистки данных и подготовки к анализу. 

Задание: 

Часть 1. Очистка клиентов
Напиши функции и очисти таблицу customers:

clean_name(x) — убрать обращения, сжать пробелы, формат 'Charles Dickens'

clean_phone(x) — только цифры, если меньше 10 цифр → np.nan, вернуть строку

clean_city(x) — убрать пробелы, привести к формату 'Moscow' (первая буква заглавная)

'SPb' и 'Spb' → 'SPb' (это исключение, аббревиатура)

Часть 2. Очистка заказов
clean_amount(x) — извлечь число float. $, €, руб., запятые и точки-разделители тысяч убрать

clean_status(x) — привести к единому виду:

'Done', 'done', 'DONE' → 'Done'

'Pending', 'pending' → 'Pending'

'Canceled', 'CANCELED' → 'Canceled'

None → np.nan

Часть 3. Универсальная очистка
Создай clean_dataframe(df, column_map) и примени к обеим таблицам через разные словари

Часть 4. Объединение и дубликаты
Соедини очищенные таблицы через merge 

Удали дубликаты заказов (одинаковые Client_ID и Amount — дубликат)
